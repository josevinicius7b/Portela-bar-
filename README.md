Projeto acadêmico de desenvolvimento de um sistema web para o Portela Bar, 
desenvolvido como parte de um Projeto Integrador (PI). 
O trabalho tem como objetivo aplicar conhecimentos de análise, planejamento,
documentação e desenvolvimento de sistemas, considerando as necessidades do estabelecimento e a 
organização de suas informações. O repositório reúne a documentação acadêmica do projeto,
o relatório do trabalho e os diagramas de casos de uso, registrando as etapas e os artefatos produzidos durante o desenvolvimento.
O projeto proporciona a aplicação prática dos conhecimentos adquiridos ao longo do curso, contribuindo para o desenvolvimento de competências técnicas,
organização de requisitos e elaboração de documentação de software.
